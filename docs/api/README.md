# Especificación de la API

El archivo [openapi.yaml](openapi.yaml) documenta los endpoints implementados
del MVP con OpenAPI 3.1. Puede abrirse con Swagger Editor, Postman o Insomnia
para consultar rutas, cuerpos JSON, validaciones y respuestas.

La fuente de verdad en ejecución sigue siendo FastAPI: en el entorno local se
puede consultar `http://localhost:8000/openapi.json` y la interfaz generada en
`http://localhost:8000/docs`.

La especificación YAML describe únicamente endpoints ya implementados. Las
rutas de integración con RADIA se documentarán cuando exista un contrato
acordado con el semillero.
